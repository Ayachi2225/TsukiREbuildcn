Added 2026-11-07. The function map ([FUNCTION-MAP.md](FUNCTION-MAP.md)) counted a native function as handled when the
port cites it ("explicit", 259) or visibly does what it does ("covered", 194). Neither means every input the function
reads is used the same way. The motion code was counted as explicit while the port read 11 of a keyframe's 28 fields,
which cut Neco-Arc off in QA_17 and left linked layers unclipped (checklist V11, V12). Every function below needs the
same check before it is trusted.

**How to check one:** read the function in the listing (`data/tsuki/gen/main/code_*.cpp`, Ghidra for the large
ones) and list everything it reads: command arguments, record and state fields, table columns, flag bits, globals.
For each, find where the web uses it and confirm the same units, defaults, holds and conditions. Where it draws, compare
a native frame (see the note on native runs: a copy of the user's save, then the web's scene buffer with the text window
laid over it). Mark `[x]` with `— checked YYYY-MM-DD: <what was compared>`; a difference becomes a new item in
[FIX-CHECKLIST.md](FIX-CHECKLIST.md), and the box is ticked once that item is done.
