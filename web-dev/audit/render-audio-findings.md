## Shader evidence provenance

The module has a 24-byte resource registration table beginning at `0x264668`, mapping shader file names to shader-object slots. Its order independently agrees with the renderer's mode-to-shader mapping. Local `framework/tools/maxwell/containers.py` was used to parse each BNSH stage, hashing the exact Maxwell code as SHA-1 truncated to16 hex digits. That hash selects the existing `data/tsuki/spirv/<hash>.spv` produced from the original shader; `/opt/homebrew/bin/spirv-cross <path> --version 450` was used to inspect its GLSL math. ## Known approximation checklist

These are fidelity differences or unverified approximations, not new claims that an entire subsystem is missing.

- **Texture conversion is lossy:** [convert.py:90](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web-dev/tools/convert.py:90) uses AVIF quality 70. Of 16294 indexed image sizes,729 use a stored scale below 1.0 (minimum .25). These are deliberate storage tradeoffs; the output cannot be pixel-identical to the original. Movie playback, by contrast, points at original MP4 bytes through `/rom/movie/`; there is no evidence here that movies were re-encoded.
- **Blur is regenerated, not the authored texture variant:** [renderer.js:399](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/renderer.js:399) downsamples large radii and rounds radii, then uses a separable box kernel (`FS_BOX`, line242). The scripts have8762 `SNX4` calls in435 scripts. Previously measured blur similarity is not a full equivalence guarantee, and no exception/fallback pack is used by the current `drawLayer` path.
- **Motion interpolation is not fully verified:** [animation.js:13](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/animation.js:13) substitutes familiar easing formulas; line125 uses one-sided Hermite slopes. Native interpolation has a separate tangent routine `0x972c0` called from `0x97710` (`code_012.cpp:8887`) and easing helper `0x961b0`.72 exported keyframes use cubic mode1. Exact cubic/elastic/back parity remains unproved, as the existing animation notes also state.
- **Quake, sway, speed lines and grain use a replacement RNG:** [effects.js:6](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/effects.js:6) and [screenfx.js:12](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/screenfx.js:12). The count/geometry distribution and phase sequence are not verified against native execution. The sway sampler chooses one period per axis, while exact per-cycle native period behavior is not established here.236 distinct script files use `SQK2` (see census for exact counts of other effect types).
- **Focus-line geometry is guessed:** [renderer.js:506](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/renderer.js:506) fixes outer width at14px and length2600px; original constants were not recovered.26 `FCLN` calls in19 scripts. Types1–3 are not drawn but are not used by the current script set.
- **Layer-mask softness is assumed:** [vm.js:690](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/js/vm.js:690) expands the four-bit field into steps of16. There are111 `STTR` calls in39 scripts, including41 removals. Mask texture timing/softness need native frame comparison.
- **Story typography uses host fonts and browser layout:** [style.css:1](/Users/h009/Downloads/tsukire-pc-port/tsukire-pc-port/web/app/style.css:1) uses Georgia/Times, fixed42px text and DOM line wrapping; intro uses Times at50px. Only flowchart/music explicitly load game fonts in CSS. Native story font selection/metrics, ruby baseline, shadows, line positioning and typewriter cadence require direct comparison, especially across operating systems.
- **Click-marker phase/position:** CSS restarts the animation each display; the original uses a running frame counter, and the native text reference for mark height is not fully traced. See current `ANIMATIONS.md:327` and `main.js:54`.
- **Sound-effect conversion is lossy:** DSP-ADPCM is decoded to PCM and re-encoded as Opus64k/96k at `convert.py:235`. Voices/music are rewrapped from existing Opus packets instead; no codec-loss claim is made for those streams.
- **Audio phase is not serialized:** `audio.js:219` snapshots music identity/volume and looped-SE names/volume only. Restore preserves matching currently playing tracks or restarts from zero; playback offset, fades and one-shots are absent. Parent UI/save findings cover this behavior and the question of exact native save semantics.
- **Processed-image cache commands are reduced to preloading:** `SPFC`/`SPRD` only load the named image (`vm.js:792`); extra processing parameters and cache-slot identity are not reproduced. Precise visible differences remain unresolved until their native consumers are traced.

## Unknowns and bounded negatives

- The script `10_00_ARC10_7_2B` contains literal `STMA(27,101960)` at op853. The raw patched script is `web-research/extracted/scripts_patch/0347.txt`, byte offset14359. `animations.json` contains only1..24192, so the web warns and omits it. The native response to the out-of-range id is unknown; this is not evidence that an additional valid track101960 exists. The parent REA smoke run observed the warning even though its UI reported no script errors.
- Native full-page window styles, Ciel-specific click mark selection, inline glyph definitions, raster/haze/wave/mesh shaders, all audio-option semantics, exact music-loop points and original fade scheduling need additional native tracing or controlled original-game captures.
- The finite checked shader set does not prove every other blend mode is accurate. Web modes2/3 take the ordinary alpha-blend path; the13 explicit mode2 call sites should be traced against native's fixed pipeline before deciding whether this is incorrect.
- Gallery pack precedence was investigated with the UI audit agent. Native image lookup itself prefers `allpac`, then `allpacml`, then `allpaccg`, so same-name pack collisions are **not** enough to call current `image_table` precedence wrong. Gallery rectangle, zoom and pan omissions are in the parent UI report.
- Native game rendering was not launched; no original/web screenshot pair, timed-motion comparison, sound-loop listening capture, or end-to-end playthrough was performed. Missing direct file names are assessed by the parent's separate complete source inventory, not inferred from an unconverted cache entry.
