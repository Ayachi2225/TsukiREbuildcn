# What's left to do

Everything still open in the web port on 2026-11-08, most important first. Finished work is not listed. Items done since
are ticked, and new ones found along the way are added at the end of their section (112 on).

**How it's ranked.** First by what goes wrong for the player: the wrong scene or sound, then a control that behaves
differently, then a look or timing difference. Then by how often a player meets it. Story scenes sit high because they
have come first all along. Inside the small-things sections the order is looser, and items are grouped by screen so one
session can take a whole screen.

**IDs.** `N2-n` is the finding's number in [FUNCTION-MAP.md](FUNCTION-MAP.md). The evidence (native addresses, port
lines, which scenes reach it) is in [function-map/](function-map/). An entry with several IDs is one fix.

**How sure.** The findings were read from the game's code and not seen running. Of those tried so far, 94 were fixed
and 2 did not reproduce on native frames, so compare each one with the game as it is fixed. Priority 1 and the main
priority 3 items were re-checked against today's code. `gallery.js` has not been edited since its findings were
written, so priority 4 stands as recorded.

**Mark an item** by changing `[ ]` to `[x]`.
